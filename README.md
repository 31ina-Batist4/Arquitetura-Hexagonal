# Arquitetura Hexagonal
# 📦 CRUD com Arquitetura Hexagonal#Ports and Adapters)**, com foco em boas práticas, baixo acoplamento e alta testabilidade.

O objetivo é separar claramente as responsabilidades entre **domínio**, **aplicação** e **infraestrutura**, utilizando tecnologias modernas amplamente adotadas no mercado.

---

## 🧱 Tecnologias Utilizadas

- **Java 17**
- **Spring Boot 3**
- **Spring Data MongoDB**
- **Apache Kafka**
- **Gradle**
- **MongoDB**
- **REST API**

---

## 🏗️ Arquitetura Utilizada

O projeto segue o padrão **Arquitetura Hexagonal (Ports and Adapters)**, que promove:

- Independência do framework
- Domínio isolado de detalhes técnicos
- Facilidade de testes
- Facilidade de troca de tecnologias externas
